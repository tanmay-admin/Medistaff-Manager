# Medistaff-Manager
Employee Management System for managing employee attendance, payroll, leave records, and employee information with database integration.

## About the Project
Medistaff Manager is an Employee Management System developed for Symbiosis Co-op Pharmaceuticals Ltd., Sangli.

The application helps manage employee information and streamline daily employee management activities.

## Features
- Employee information management
- Attendance management
- Payroll management
- Leave management
- Employee dashboard

## Database
- MongoDB
- Employee data storage and management
- Database operations for retrieving and updating records
